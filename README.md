# VERITAS-ассистент

ИИ-помощник для службы ухода VERITAS Pflegedienst Berlin. Отвечает родственникам и клиентам по-русски и по-немецки, текстом и голосом, и собирает заявки на обратный звонок. Работает только на Gemini (Google).

## Что умеет

| Функция | Модель Gemini |
|---|---|
| Текстовый чат по базе знаний VERITAS (DE/RU) | `gemini-3.8-flash` |
| «Поговорить с помощником»: голосовой разговор, как по телефону | `gemini-3.8-live` |
| Кнопка 🎤 в чате: сказал, и текст отправился | `gemini-3.5-transcribe` (если вернёт пусто, работает запасной вариант через `gemini-3.8-flash`) |
| «Читать ответы вслух» | `gemini-3.8-flash-lite-tts` |
| Заявки на обратный звонок | Supabase, проект **Assistants** |
| Уведомление о заявке в Telegram | по желанию |
| Закрыть демо кодом доступа | `DEMO_ACCESS_CODE` |
| Виджет-кнопка для их сайта | файл `public/widget.js` |

Нужен один ключ: `GEMINI_API_KEY`. Все модели можно поменять в `.env.local`, код трогать не нужно.

## Структура

```
tenant/knowledge.md   ← база знаний (всё, что бот знает о VERITAS). Правишь здесь.
tenant/company.json   ← название, телефоны, адреса, быстрые вопросы, id компании ("veritas")
lib/prompt.ts         ← правила поведения бота (чат и голос)
app/api/chat          ← чат (поток ответа)
app/api/live          ← выдаёт одноразовый ключ на голосовой разговор
app/api/transcribe    ← речь → текст
app/api/tts           ← текст → речь
app/api/lead          ← заявки → Supabase / Telegram
components/*          ← интерфейс
public/widget.js      ← кнопка-чат для чужого сайта
supabase/leads.sql    ← структура базы (уже создана в проекте Assistants)
```

## Как устроен голосовой режим и почему так

1. Браузер просит у нашего сервера одноразовый ключ (`/api/live`).
   *Почему:* настоящий `GEMINI_API_KEY` никогда не попадает в браузер, его нельзя украсть.
2. В этом ключе уже «зашиты» модель, голос, инструкции и база знаний. Браузер не может их изменить.
3. Браузер напрямую соединяется с Gemini Live: микрофон → Gemini, голос Gemini → динамик. Задержка минимальная.
4. Если человек хочет обратный звонок, Gemini сама вызывает функцию `save_callback_request`, и заявка уходит в базу.

## База данных Supabase «Assistants»

Одна база на все демо-компании. Каждая запись помечена компанией:

- `companies`: список компаний (`veritas`, `dakos`, …)
- `leads`: заявки, поле `company_id` указывает, чья это заявка

Посмотреть заявки VERITAS в Supabase → SQL Editor:

```sql
select created_at, source, name, phone, district, concern, status
from leads where company_id = 'veritas' order by created_at desc;
```

**Ключ.** Лучше `SUPABASE_SECRET_KEY` (Project Settings → API Keys → Secret keys). Publishable key тоже работает: для него в базе настроено правило «можно только добавлять заявки, читать нельзя».

## Запуск на компьютере

1. Установи Node.js 20 или новее.
2. В папке выполни `npm install`.
3. Проверь `.env.local` (образец — `.env.example`).
4. Выполни `npm run dev` и открой http://localhost:3000.

## Публикация на Vercel

1. Код уже лежит в GitHub: `aslanzubairaev2/veritas`.
2. vercel.com → **Add New → Project →** выбери репозиторий `veritas`. Framework определится сам (Next.js).
3. Перед Deploy открой **Environment Variables** и перенеси строки из `.env.local`. Проще всего вставить весь файл целиком: Vercel умеет разбирать вставленный `.env`.
4. **Deploy**. Дальше каждый `git push` обновляет сайт сам.
5. После смены ключа в Vercel сделай **Redeploy**.

## Telegram-уведомления (по желанию)

1. В Telegram: @BotFather → `/newbot` → токен в `TELEGRAM_BOT_TOKEN`.
2. Напиши своему боту любое сообщение.
3. Открой `https://api.telegram.org/bot<ТОКЕН>/getUpdates`, найди `"chat":{"id":...}` → это `TELEGRAM_CHAT_ID`.

## Как обновить знания бота

Правь `tenant/knowledge.md` → `git push` → через минуту бот знает новое. Факты о фирме он берёт **только** из этого файла.

## Важно: демо и право

- Пока фирма не наняла тебя: `DEMO_BANNER=true` и задан `DEMO_ACCESS_CODE`. *Почему:* открытый сайт с их названием можно принять за официальный сервис.
- Бот сразу говорит, что он ИИ (требование AI Act ЕС).
- Переписка не сохраняется. Сохраняются только заявки, и в чате только с галочкой согласия (DSGVO).
- Для настоящей работы с клиентами нужен платный аккаунт Gemini API (на бесплатном Google может использовать данные для улучшения моделей) и договор об обработке данных.

## Для следующей фирмы (например, DAKOS)

1. Скопируй папку.
2. Замени `tenant/company.json` (поле `"id": "dakos"`) и `tenant/knowledge.md`.
3. Компания `dakos` в базе уже есть. Для новой добавь строку в `companies` (пример в `supabase/leads.sql`).
4. Создай отдельный проект в Vercel с теми же ключами.
